# Archive

`skills/` contains retired workflows, including the former standalone Token DD recipe. These are historical references, not installable skills. Their entry files are named `ARCHIVED.md` so skill discovery does not load them. Active packages live in the repository root `skills/` directory.

Legacy runtime definitions remain available for saved results and explicit CLI compatibility. Catalog generation excludes the legacy family and must not recreate these packages.

Token due diligence is now published as one **Token DD** skill (`skill-token-dd-score`), with Standard and Advanced modes. Its ID remains stable to preserve existing statistics and installed integrations.

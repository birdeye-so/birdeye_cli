# Skill chain support and limitations

<!-- Generated from workflow definitions by npm run skills:sync. -->

This table describes the skills implemented by this CLI, not every network supported by Birdeye. Checked against the execution definitions and request catalog on 2026-10-28. The catalog contains 20 current skills; four older instruction packages remain for compatibility.

Live requests require a Birdeye key with access to every requested endpoint; coverage may be incomplete. Plans fetch bounded pages, not complete populations. CU estimates exclude retries and are not confirmed billing. Skills perform research, not trading, continuous monitoring or copy-trade backtesting.

## Endpoint support versus skill support

`birdeye-cli cases --short` reports each current skill's `supportedChains` and `limitations`. `birdeye-cli capabilities --short` reports the implemented `chains` for each raw operation; its singular `chain` is the default. `birdeye-cli chains` summarizes implemented chains and scope. `chains --refresh` queries Birdeye's wider network list and does not enable new CLI support. Imported workflows and existing demo recipes remain Solana-only.

The raw `market.token-list`, `token.security` and `token.top-traders` operations support the five Price Surge chains. Other raw operations remain Solana-only. For EVM calls use a 20-byte `0x` contract address; Solana addresses must decode to 32 bytes. A supported chain does not guarantee that every upstream field is populated.

[Token List V3](https://data.birdeye.so/docs/data-api/tokenmarket-list/get-defi-v3-token-list) documents additional networks outside this implementation, but not Arbitrum. [Holder Profile](https://data.birdeye.so/docs/data-api/holder/get-token-v1-holder-profile) documents Robinhood as well as Solana; this CLI's holder-profile operation and Price Surge holder-health step remain Solana-only. [Top Traders](https://data.birdeye.so/docs/data-api/wallet-networth-pnl/get-defi-v2-tokens-top-traders) has Solana-specific tag/holder options. [Security](https://data.birdeye.so/docs/data-api/security/get-defi-token-security) returns chain-dependent fields. Upstream declarations were rechecked on 2026-10-28; no live paid endpoint validation is implied.

# How to Use the CSV Download Feature on Birdeye

## :warning: Important Limits for CSV Downloads:

### For PRO Users:

* You can download up to 100 files per month.
* Each file can contain a maximum of 500,000 records.

### For Higher Limits:

If you need higher limits, such as downloading more than 100 files per month or files containing more than 500,000 records, you can switch to using [Birdeye Data Services (BDS)](https://bds.birdeye.so/) (additional data usage fee might be applied).

## Step-by-Step Instructions to Download Data in CSV Format:

* **Log in to your Birdeye PRO Account**
  * Log in page: [https://birdeye.so/user/sign-in](https://birdeye.so/user/sign-in)
  * If you have not upgraded to PRO Membership, you can upgrade [HERE](https://birdeye.so/pro#traders).
* **Navigate to the Data Section**\
  Once logged in, go to the relevant section where you wish to download data, for example:
  * [Find Gems](https://birdeye.so/find-gems?chain=solana)
  * [Find Trades](https://birdeye.so/find-trades?chain=solana)
* Select the Data You Want to Export\
  Filter or select the data based on the specific parameters you want (e.g., date range, volume, etc.).
* Click on the CSV Export Button\
  After filtering the data, locate the option to "Export" or "Download" the data.
* Download the CSV file.\
  Visit your profile page ([https://birdeye.so/user/profile](https://birdeye.so/user/profile)), scroll down to the Download Center and download the file you exported.

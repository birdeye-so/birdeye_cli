# **Using the Profile Page to Monitor Your API Usage**

Birdeye provides you with a user-friendly Profile page that allows you to closely monitor and manage your API usage. This page empowers you with valuable insights, tools, and control to optimize your experience with our APIs. Here's a step-by-step guide on how to navigate and leverage the features available on the Profile page:

URL: [https://bds.birdeye.so/user/metrics](https://bds.birdeye.so/user/metrics)

# **1. Accessing Your Profile:**

* Log in to your Birdeye account.
* Click on your profile picture or name in the top right corner of the Birdeye website to access the drop-down menu.
* Select "Profile" from the menu to navigate to your Profile page.

# **2. Monitoring API Metrics:**

* On the Profile page, you'll find a comprehensive overview of your API usage metrics.
* Visualize the Call Methods and Status over time to gain insights into your API activities.
* Dig deeper by exploring the detailed metrics provided, helping you understand the nature of your API calls.

# **3. Viewing API Details:**

* Access a list of origin, IPs, and user agents that have been using your API key.
* Understand the sources of API requests and ensure that your key is being utilized as intended.

# **4. Generating New API Keys:**

* If necessary, you can generate new API keys to enhance security or segregate usage.
* Click on the "Generate New API Key" option to create a new key.

# **5. Managing Key Access:**

* Once you've generated new API keys, you can configure access restrictions, including rate limits per API keys.
* Utilize the blacklist and whitelist features to control who can or cannot access specific keys based on IP, origin, or referrer.

# **6. Viewing Audit Logs:**

* Gain transparency into your API activities by reviewing the Audit log.
* The Audit log provides a chronological record of user actions, API key creations, modifications, and more.

By using the Profile page, you gain a powerful toolset to effectively monitor and manage your API usage on Birdeye. From tracking metrics to generating new keys and enhancing security, this page offers you the control you need to ensure a seamless and secure experience while utilizing our APIs. Should you have any questions or need assistance, don't hesitate to reach out to our support team. Happy monitoring!

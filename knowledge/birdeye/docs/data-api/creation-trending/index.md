# Creation & Trending

The Creation & Trending group helps you find recently interesting tokens and understand how a token first came into existence.

Use this group when you need:
- creation transaction context for a token
- trending token discovery across supported chains

## Which endpoint should I use?

| If you need... | Use this endpoint |
| --- | --- |
| The token's creation transaction context | `Token - Creation Token Info` |
| The currently trending token list | `Token - Trending List` |

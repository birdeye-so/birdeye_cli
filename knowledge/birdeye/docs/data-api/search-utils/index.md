# Search & Utils

The Search & Utils group helps you find tokens and markets quickly, then inspect account-level credit usage for operational visibility.

## Which endpoint should I use?

| If you need... | Use this endpoint |
| --- | --- |
| Search by name, symbol, token address, or market address | `Search - Token, market Data` |
| Credit usage for the current account | `Utils - Credits Usage of current account` |

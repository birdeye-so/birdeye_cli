# Blockchain

The Blockchain group provides low-level network metadata and chain-state utilities that support the rest of the data API.

Use this group when you need:
- the set of networks Birdeye currently supports
- the latest trade-observed block number on a chain

## Which endpoint should I use?

| If you need... | Use this endpoint |
| --- | --- |
| The list of supported Birdeye networks | `Supported Networks` |
| The latest trade-observed block number | `Trades - Latest Block Number` |

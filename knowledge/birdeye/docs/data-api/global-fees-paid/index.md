# Global Fees Paid

The Global Fees Paid group tracks fee-generation activity for tokens across supported intervals.

## Which endpoint should I use?

| If you need... | Use this endpoint |
| --- | --- |
| Fee metrics for one token | `Token - Fee (Single)` |
| Fee metrics for many tokens | `Token - Fee (Multiple)` |

## Notes

- Global fee data is Solana-only in the current API.
- `alltime` data is available starting from **May 26, 2026 at 19:00 UTC**.
- The multi endpoint is best for comparison and ranking; the single endpoint is best for token-detail views.

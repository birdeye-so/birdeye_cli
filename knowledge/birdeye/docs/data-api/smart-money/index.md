# Smart Money

The Smart Money group focuses on tokens being accumulated, traded, or surfaced by stronger-performing wallets.

## Which endpoint should I use?

| If you need... | Use this endpoint |
| --- | --- |
| Tokens ranked by smart-money activity and trader style | `Smart Money - Token List` |
| Token money flow grouped by wallet cohort and time frame | `Token Money Flow` |

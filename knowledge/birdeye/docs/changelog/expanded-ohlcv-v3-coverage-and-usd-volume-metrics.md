# Expanded OHLCV V3 Coverage and USD Volume Metrics

### 🟢 Updates

**✅ OHLCV V3 Now Supported on Ethereum, BNB Smart Chain, and Base**

* Gain access to high-resolution OHLCV data for tokens and pairs across:
  * Ethereum
  * BNB Smart Chain (BSC)
  * Base
* Data is available starting from `May 9, 2025 00:00 UTC`

📘 Docs:\
👉 [OHLCV Token V3](../data-api/price-ohlcv/get-defi-v3-ohlcv#/)

👉 [OHLCV Pair V3](../data-api/price-ohlcv/get-defi-v3-ohlcv-pair#/)

**✅ Introduction of`v_usd` – Volume in USD**

* A new field `v_usd` is now included in **OHLCV V3 responses.**
* Reflects trading volume in USD

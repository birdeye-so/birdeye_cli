# 2026.04.20 - Release Ethereum and Monad support for Token Creation Info API

Now support Token Creation Info on Ethereum and Monad.

## Features

### Token - Creation Info

[GET /defi/token_creation_info](../data-api/creation-trending/get-defi-token-creation-info)

* Add Monad chain support

## Summary

This release expands the Token Creation Info API to include Ethereum and Monad. The endpoint now supports **Solana**, **BSC**, **Base**, **Ethereum**, and **Monad**.

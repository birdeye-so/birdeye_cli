# 2025.12.10 - Release support for meme on BSC, Monad

Now support fetching meme information on BSC (four.meme) and Monad (nad.fun)

## New Features

### Token - Meme info on BSC and Monad

#### [GET /defi/v3/token/meme/list](../data-api/meme/get-defi-v3-token-meme-list) 

#### [GET /defi/v3/token/meme/detail/single](../data-api/meme/get-defi-v3-token-meme-detail-single)

**Features:**

* Now support
  * four.meme on BSC: From 2025/11/20
  * nad.fun on Monad: From 2025/11/17

### Token - Trending List

#### [GET /defi/token_trending](../data-api/creation-trending/get-defi-token-trending)

**Features:**

* Add more interval to 1h, 4h, 24h for trending.

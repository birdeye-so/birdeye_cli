# 2025.10.20 - Release SUBSCRIBE_TOKEN_STATS WebSocket for EVM chains

## New Features

### `SUBSCRIBE_TOKEN_STATS` WebSocket for EVM chains

Beside Solana, you can now stream token stats WebSocket on 8 new EVM chains, including Base, BNB Chain, Ethereum, Polygon, Arbitrum, Optimism, Avalanche and ZkSync.


This WebSocket serves as a real-time counterpart to Token Overview API.

# 2025.06.25 Token List V3 and V3 Scroll now available on Base

**Token List V3** and **Token List V3 Scroll** are now available on the **Base**

**Impacted API Endpoints:**

* [GET /defi/v3-token-list](../data-api/tokenmarket-list/get-defi-v3-token-list#/)
* [GET /defi/v3-token-list-scroll](../data-api/tokenmarket-list/get-defi-v3-token-list-scroll#/)

Developers can now fetch updated and chain-specific token lists for the Base network, enabling broader DeFi integrations and better token visibility.

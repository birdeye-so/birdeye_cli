# 2026.01.20 - Release token holder distribution on Solana

Token Holder Distribution API is now available for Solana

## New Features

### Token - Holder Distribution

#### [GET /holder/v1/distribution](../data-api/holder/get-holder-v1-distribution)

**Features:**

* Retrieve holder distribution statistics of a token
* Get up to 10,000 holders per request

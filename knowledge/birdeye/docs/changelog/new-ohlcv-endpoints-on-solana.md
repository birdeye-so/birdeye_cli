# New OHLCV Endpoints on Solana

**New OHLCV endpoints on Solana, support`1s`, `15s` and `30s` intervals**  🟢 **`New`**

* [OHLCV V3 for token](../data-api/price-ohlcv/get-defi-v3-ohlcv#/)
* [OHLCV V3 for pair](../data-api/price-ohlcv/get-defi-v3-ohlcv-pair#/)

**Note:**

* Sub-minute intervals data starts from `May 2, 2025 16:30 UTC`
* Empty candles are not displayed
* Data Availability & Retention
  * 1s: Up to 2 weeks
  * 15s and 30s: Up to 3 months

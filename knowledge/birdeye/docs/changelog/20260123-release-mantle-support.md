# 2026.01.23 - Release Mantle support

Now support Mantle APIs and Websocket

BDS provides a complete suite of APIs and streaming endpoints for Mantle, enabling developers to build dashboards, trading bots, explorers, analytics tools, and DeFi applications.

Fogo [pair overview APIs](../data-api/stats/get-defi-v3-pair-overview-single) are also supported.

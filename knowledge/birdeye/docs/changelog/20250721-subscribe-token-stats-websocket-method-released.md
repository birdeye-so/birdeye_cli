# 2025.07.21 - SUBSCRIBE_TOKEN_STATS WebSocket Method Released

**Added: SUBSCRIBE\_TOKEN\_STATS WebSocket method**

* Streams real-time token data including price, volume, trades, and supply
* WebSocket-based upgrade of the existing [token\_overview REST API](../data-api/stats/get-defi-token-overview#/)
* Supports multiple time intervals (e.g., 30m, 1h, 4h, 24h)
* Currently available on the Solana network

📄 Docs: [Subscribe Token Stats](https://docs.birdeye.so/docs/subscribe_token_stats#/)

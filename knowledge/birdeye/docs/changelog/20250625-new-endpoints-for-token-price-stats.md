# 2025.06.25 - New Endpoints for Token Price Stats

**🟢 Token Price Stats**

You can now track Token Price Stats on **All Supported Chains** using our latest API endpoints. This update makes it easier to monitor Real-time token price stats across Defi Protocols.

🔗 New endpoints available for both single and batch queries

* [Single](../data-api/stats/get-defi-v3-price-stats-single#/): `/defi/v3/price/stats/single`
* [Multiple](../data-api/stats/post-defi-v3-price-stats-multiple#/): `/defi/v3/price/stats/multiple`
